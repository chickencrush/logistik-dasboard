Pasang CC Logistik

Aplikasi ini adalah PWA, bukan file APK/EXE. Setelah dipasang, ikon dashboard muncul seperti aplikasi di perangkat Anda.

  • Android / Chrome: menu ⋮ → Instal aplikasi atau Tambahkan ke layar utama.
  • iPhone / Safari: Bagikan → Tambahkan ke Layar Utama.
  • Komputer: gunakan opsi instalasi aplikasi pada menu browser jika tersedia.

Buka melalui alamat HTTPS GitHub Pages, bukan file HTML lokal. Data baru tetap memerlukan internet.
